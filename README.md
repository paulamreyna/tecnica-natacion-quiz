# 🏊 Swim Quiz · Técnica de Natación

Juego interactivo bilingüe (español / English) hecho con **HTML, CSS y JavaScript** puro.
Se muestran ejercicios de natación y tenés que decidir si la técnica descripta es **Correcta ✅** o **Incorrecta ❌**.

Interactive bilingual game (Spanish / English) built with plain **HTML, CSS and JavaScript**.
It shows swimming drills and you decide whether the technique is **Correct ✅** or **Incorrect ❌**.

## Cómo jugar / How to play

1. Abrí `index.html` en el navegador / Open `index.html` in your browser.
2. Elegí idioma (ES / EN) arriba a la derecha / Pick a language (top right).
3. Respondé cada ejercicio y leé la explicación / Answer each drill and read the explanation.

## Estructura / Structure

```
index.html   → estructura / markup
style.css    → estilos y animaciones / styles & animations
script.js    → lógica del juego y textos / game logic & texts
```

Para agregar ejercicios, sumá objetos al array `EXERCISES` en `script.js`.
To add drills, add objects to the `EXERCISES` array in `script.js`.
